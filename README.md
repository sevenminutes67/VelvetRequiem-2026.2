# SiteVelvet
A Velvet Requiem é um projeto iniciado por nós 3, com o objetivo de elevar o mercado indie Brasileiro. Com isso em mente, resolvemos criar um jogo de terror com estetica de Ps1, ao estilo de outro estudio indie bem conhecido por jogos nesse estilo, a Puppet Combo. E uma forma de arrecadarmos verba para o desenvolvimento é a criação de um site para o usuario adquirir o Jogo (ainda sem nome), além de possuir "niveis" de compra, indo de 1 até 3 e, conforme o nivel sobe, o usuario, além de receber o jogo, poderá receber concepts arts, atualizações do estado atual de desenvolvimento do jogo e etc.





Participantes: Mikael André Ortiz Pelegrino, João Gabriel Marques de Miranda, Daniel Henrique Delmônico Cintra
